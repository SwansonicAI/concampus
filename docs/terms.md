# Terms

One word, one meaning, in everything ConCampus shows: labels, pages, buttons, messages and the defaults of the texts
under Einstellungen › Texte. The words are those German Musikhochschulen use themselves, on their websites and in their
Ordnungen (the demo's: HfM Weimar, <https://www.hfm-weimar.de/>). The search still finds a page by the words avoided
here (`core/synonyms.py`).

| Concept | Say | Not | Why |
|---|---|---|---|
| Applying for a place, the whole process | Bewerbung; the offices' list: Bewerbungen | Aufnahme, Zulassung (as an area) | Weimar's menu: „Bewerben“, „Nach der Bewerbung“; Aufnahme is a recording |
| The audition for a place | Eignungsprüfung | Aufnahmeprüfung | the Ordnungen: Eignungsprüfungsordnung (EPO) |
| The decision on a place | Zulassung, Ablehnung | Aufnahme | a step of the Bewerbung, as in the EPO, not its name |
| A recording | Aufnahme, Video | | the one meaning left to Aufnahme |
| A course of any kind | Lehrveranstaltung | Veranstaltung on its own, Kurs | Weimar: „Lehrveranstaltungsverzeichnis“ |
| The kind with shared dates | Gruppenunterricht | Lehrveranstaltung (that is every kind) | |
| The kind with one time per person | Einzelunterricht | Klasse | |
| A teacher's reply in semester planning | Antwort | Rückmeldung | |
| The list of a semester's courses | Lehrveranstaltungsverzeichnis or Vorlesungsverzeichnis | | both in use; never „Veranstaltungen“ |
| A concert or other event | Veranstaltung | Lehrveranstaltung | Weimar: „Veranstaltungskalender“, „Veranstaltungsbüro“ |
| Re-registering for the next semester | Rückmeldung | Rückmeldung for feedback | everywhere: Rückmeldung, Semesterbeitrag, Rückmeldefrist |
| Feedback, a report of a barrier | Hinweis | Rückmeldung, Meldung | |
| A report to a health insurer | Meldung | | the official term (Studierendenmeldeverfahren) |
| Registering for a course or an exam | Anmeldung, Abmeldung | Anmeldung for signing in | |
| Signing in | Zugriff, anmelden (only as the verb on the sign-in page) | Anmeldungen as a list of sign-ins | Mein Konto: „Zugriffe“ |
| Enrolment at the Hochschule | Immatrikulation, Exmatrikulation; Ersteinschreibung for the first | Einschreibung | Ersteinschreibung: the official statistics' term |
| Whom to ask | Ansprechperson, zuständig | Ansprechpartner | Weimar: „Ansprechpersonen“ |
| Staff who teach | Lehrende; one: Lehrperson; Lehrbeauftragte where it matters | Dozent, Lehrer | Weimar: „Lehrende“ |
| The teacher in the main subject | Hauptfachlehrer:in; asked for when applying: Wunschlehrer:in | | usual at Musikhochschulen |
| A teacher's students in their main subject | Klasse | Klasse for Einzelunterricht | |
| An office of the Hochschule | Amt | Abteilung, Stelle | ConCampus' own: Ämter und Rechte |

Not renamed, though they hold old words: the placeholders of the texts (`{veranstaltung}`), which texts the Hochschule
has edited use, and the URLs (`/aufnahme/`), which messages already sent link to.
